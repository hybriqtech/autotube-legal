Privacy Policy

autotube is a personal application used only by its owner to manage the owner's own YouTube channel.

Data accessed

With the owner's authorization, the app uses the YouTube Data API and YouTube Analytics API to upload videos and read the channel's own performance metrics.

Data storage and sharing

Authorization tokens and metrics are stored locally on the owner's computer. No data is collected from other users, and no data is sold, shared or transferred to third parties.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

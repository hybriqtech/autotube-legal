Privacy Policy

Last updated: 24 October 2026.

autotube is a personal application used only by its owner to publish videos to the owner's own Syncopixel accounts on YouTube, Instagram and TikTok.

Data accessed

With the owner's authorization, the app uses:

  • the YouTube Data API and YouTube Analytics API, to upload videos and read the channel's own performance metrics;
  • the Instagram API (through the owner's Facebook Page), to publish Reels to the owner's own Instagram account;
  • the TikTok Content Posting API, to send videos to the owner's own TikTok account.

The app only accesses the owner's own accounts. It does not read, collect or process data about any other person.

Data storage and sharing

Authorization tokens, the published videos and their metrics are stored locally on the owner's computer. No data is collected from other users, and no data is sold, shared or transferred to third parties.

Google API Services

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Data deletion

The only user of the app is its owner. To delete the data the app holds, the owner removes the local tokens and revokes the app's access in each platform's settings (Google account permissions, Facebook "Business Integrations", TikTok "Manage app permissions").
